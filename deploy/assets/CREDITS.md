## Maps

There is no third-party map data in this repository. The location panel on the
site is a stylised SVG diagram drawn in `app.js`, labelled "not to scale", with a
"Get directions" link to the real map.

A bundled static map was attempted and abandoned: OpenStreetMap's tile servers
refuse the request (`403 Access blocked — not following the tile usage policy`),
and no other provider's terms clearly permit downloading tiles once and shipping
them inside a file that is given to a client. Drawing the diagram avoids the
question entirely and keeps the demo genuinely offline.

## Typefaces

Two sets are bundled in `assets/fonts/` as latin-subset `woff2` files and
self-hosted through stylesheets, so nothing is fetched at view time.

- `fonts.css` — Cormorant Garamond + Jost. The original pair used by the
  direction mockups. Still linked by them; superseded once a pairing is chosen.
- `fonts-pairings.css` — the three candidate pairings below.

All six families come from Google Fonts under the
[SIL Open Font License 1.1](https://openfontlicense.org/), which permits
commercial use, embedding and redistribution, including inside a single-file
HTML export. No attribution is required; it is recorded here anyway.

| Family | Files | Role |
| --- | --- | --- |
| Cormorant Garamond (300/400/500, 300 italic) | `cormorant-*.woff2` | Headings — original, superseded |
| Jost (300/400/500) | `jost-*.woff2` | Body and labels — original, superseded |
| Libre Baskerville (400/700, 400 italic) | `libre-baskerville-*.woff2` | Pairing 1 headings |
| Inter (300/400/500) | `inter-*.woff2` | Pairing 1 body and labels |
| Playfair Display (400/500/600, 400 italic) | `playfair-display-*.woff2` | Pairing 2 headings |
| Source Sans 3 (300/400/500) | `source-sans-3-*.woff2` | Pairing 2 body and labels |
| Marcellus (400) | `marcellus-400.woff2` | Pairing 3 headings |
| Work Sans (300/400/500) | `work-sans-*.woff2` | Pairing 3 body and labels |

Downloaded with `research/tools/fetch-fonts.mjs`, which also rewrites
`fonts-pairings.css`.

**Pairing 1 was chosen for the site**, which loads only Libre Baskerville and
Inter: about 230 KB of `woff2`. The other two pairings are kept so the comparison
sheet in `research/fonts/` stays reproducible offline; nothing on the site
references them. `fonts.css` still carries the superseded Cormorant + Jost pair
because the Phase 1 direction mockups link it.

> Marcellus ships a single roman face with no italic. Where it is used, italics
> are switched off rather than synthesised, so the browser never fakes an oblique.
